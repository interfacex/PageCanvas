# 页绘 PageCanvas

Chrome 网页转图片插件，支持完整导出、传统算法提取和用户自备模型的 AI 智能提取。

## 安装

1. 解压 `pagecanvas-extension.zip`。
2. 打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的 `pagecanvas-extension` 文件夹。
4. 如需处理本地 HTML，在扩展详情中开启“允许访问文件网址”。

升级 ZIP 后请在 `chrome://extensions` 中点击页绘卡片上的“重新加载”，并刷新此前已经打开的目标网页。1.0.1 起插件也会在点击整页导出或内容提取时自动补充注入内容脚本。

## 使用

- **完整导出：** 可在当前页面拖拽自由框选区域，或自动滚动并拼接整个页面。框选支持实时尺寸、重新选择、`Enter` 确认与 `Esc` 取消。
- **传统提取：** 纯本地识别正文、列表和主要图片，进入可编辑预览。
- **AI 智能提取：** 在设置页填写 OpenAI-compatible API Base URL、API Key 和模型，再由模型摘要重组。

点击任一方式只会建立选择并显示高亮；确认底部的“开始…”按钮后才执行任务。整页导出完成后，拼接结果会直接显示在预览页。

1.0.4 起导出采用两组可组合属性：导出范围默认为“整个页面”，内容处理默认为“默认 · 直接导出”。也可以组合自由框选与传统/AI 提取，此时只重排圈选范围内的内容。

1.0.5 恢复完整导出和自由框选预览中的输出分辨率选择。720、1080、1440 表示最终 PNG 宽度，图片高度按原始比例自动计算；下载和复制使用相同分辨率。

1.0.6 新增 2160、2880 和 3840 px 高清档位。预览页会显示预计宽高与百万像素；超高长图超过单张 Canvas 安全高度时自动分片下载，文件名包含分辨率与分片序号。

1.0.7 在“整个页面 + 直接导出”完成拼接后自动识别并移除左右连续的页面背景画布。只在左右背景颜色一致且检测置信度足够时裁剪，不裁页面顶部、底部或铺满宽度的正文。

1.0.8 在整页滚动捕获期间于原网页右上角显示实时进度、帧数和防切页提示。提示层会在每次截图前自动隐藏、截图后恢复，不会进入最终图片；失败时会在原页面显示重新开始提示。

1.0.9 为 Chrome 可视标签页截图增加全局频率控制。整页、自由框选和可视区域截图至少间隔 550ms，遇到截图频率配额错误会等待后自动重试一次。2160、2880、3840 px 等高清档位仍只处理已完成的截图，不会增加浏览器截图调用。

1.0.10 修复带平滑滚动或滚动吸附页面的长图拼接错位。捕获期间临时改为即时滚动并等待位置稳定，使用浏览器返回的实际滚动坐标拼接；成功或失败后都会恢复页面原有滚动样式和初始位置。

1.0.11 修复预览页打开后原网页进入后台、动画帧暂停导致整页捕获永久等待的问题。每帧滚动前先激活原网页，并为滚动稳定检测和位置恢复增加超时兜底；完成后自动返回预览页显示最终图片。

1.0.12 修复整页预览复制失败提示为 `undefined`、传统提取结果无法下载 PNG 的问题；AI 智能提取期间新增估算百分比、按钮锁定和失败恢复，并增强预览任务的并发隔离与自动打开兜底。

1.0.13 将传统/AI 文档预览按安全高度直接分片渲染，避免超长内容在分片前创建完整 Canvas；图片资源无法进入导出时自动退化为纯文字并提供具体建议。“自由框选 + AI 智能提取”确认后会在原网页右上角持续显示估算进度、失败原因和重试提示。

1.0.14 将单次 AI 模型请求等待上限从 30 秒提升至 4 分钟，并把底层 Abort/Timeout 统一转换为可操作的中文提示；修复旧页面自动补注入时遗漏框选 AI 进度依赖、导致 `PageCanvasRegionAiProgress is not defined` 的问题。

预览页可编辑文本、选择浅色/深色、720/1080/1440 宽度、隐藏图片，并下载或复制 PNG。百度网盘入口为后续扩展占位，本版不会连接网盘。

## 已知限制

- Chrome 内部页面、Chrome Web Store 等页面禁止扩展注入。
- 本地 HTML 若提示无法读取，请在扩展详情中开启“允许访问文件网址”并刷新该 HTML 页面；这是 Chrome 的安全权限，插件不能自行绕过。
- 极长页面受浏览器 Canvas 上限和内存影响；建议关闭其他高占用标签页。
- 跨域图片可能无法进入重排后的图片，此时会自动移除该图片并保留文字。
- 无限滚动页面仅导出启动任务时已加载的高度。
- AI 服务兼容性取决于其是否实现 OpenAI Chat Completions 协议及 JSON 输出。
